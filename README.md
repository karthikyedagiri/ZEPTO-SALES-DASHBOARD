# 🛒 Zepto Sales Dashboard – Power BI

## 📊 Project Overview

The **Zepto Sales Dashboard** is an interactive **Power BI data analytics project** created to analyze sales performance, orders, products, pricing, discounts, categories, cities, and influencer-driven sales.

The dashboard transforms raw sales data into meaningful **business insights and KPIs** using Power BI visualizations and DAX measures.

---

## 🎯 Project Objectives

* Analyze overall sales and revenue performance
* Track total orders and product performance
* Compare original price, current price, and discounts
* Analyze sales across different categories and cities
* Understand influencer vs. organic sales
* Monitor revenue targets and target achievement
* Identify high-performing products and categories
* Create an interactive and user-friendly dashboard

## 🚀 How to Use

1. Download or clone this repository.
2. Open `ZEPTO SALES DASHBOARD.pbit` using **Microsoft Power BI Desktop**.
3. When prompted, provide the location of the Zepto sales dataset.
4. Refresh the data.
5. Explore the interactive dashboard using the available slicers and visuals.
